语法与快捷键

        
    

    

        
Markdown 速查

        

            
## 小节小节标题（渲染为 <h3>）

            
### 子小节子标题（渲染为 <h4>）

            
**加粗** / *斜体* / ~~删除~~文字样式

            
==高亮==荧光笔高亮

            
`代码`行内代码

            
- 项目 / 1. 项目无序 / 有序列表，缩进两格可嵌套

            
- [ ] 待办 / - [x] 已办任务清单

            
> 引用引用块

            
```bash … ```代码块（可标注语言）

            
![说明](地址){50%}图片，花括号里可写宽度

            
[文字](地址)链接

            
| 列 | 列 |表格（第二行写 | --- | --- |）

            
---分割线

            
工具栏「字号 / 字体 / 颜色」字号（含自定义 px）、字体、文字颜色、背景色、段落对齐

            
工具栏「更多格式 ▾」下划线、高亮、上/下标、键盘键、提示框、折叠块、两栏、图注、B 站视频、音频…

            
粘贴 / 拖入图片自动保存到 blog_fig/ 并插入正文（PNG / JPG / GIF / WebP）

        

        
也可以直接粘贴原始 HTML，渲染时会原样保留。

        
快捷键

        

            
Ctrl + B / I加粗 / 斜体

            
Ctrl + K插入链接

            
Ctrl + S保存草稿

            
Ctrl + Enter发布到站点

            
Tab插入两个空格

            
Enter列表 / 引用会自动续行

        

        
发布时会发生什么

        
    
            
  • 生成 blog/<文件名>.html，并登记到 data.json；
    • 
            
  • 自动重算所有文章的“上一篇 / 下一篇”（含同分类），补发旧日期的文章也不会乱；
    • 
            
  • 把条目插入 blog.html 与对应分类页的文章列表；
    • 
            
  • 文件名重复时自动改用 -1、-2 后缀，不会覆盖旧文章；
    • 
            
  • 发布前会体检：图片缺 alt、本地图片不存在、占位链接 # 都会在「结构」里提示。
